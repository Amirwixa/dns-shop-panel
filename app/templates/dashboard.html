🎚️ حالت سرویس DNS

⚠️ حالت کامل: همه وب‌گردی مشتریان از سرور شما عبور می‌کند (پهنای باند و CPU بیشتر مصرف می‌شود).
⚠️ اپ‌هایی که پورت غیر وب دارند (بازی‌های آنلاین UDP، تماس صوتی/تصویری، ایمیل و...) ممکن است کار نکنند — این محدودیت ذاتی DNS است و فقط با VPN واقعی حل می‌شود.
ℹ️ نام‌های شبکه داخلی (localhost و...) خودکار مستثنی هستند و بلاک‌لیست همچنان کار می‌کند.

📖 راهنمای اتصال کاربر

۱. در پنل، کاربر را با IP عمومی او بسازید (کاربر می‌تواند با جستجوی «my ip» آن را ببیند).
۲. IP سرور (...) را به‌عنوان DNS روی دستگاه کاربر ست کنید:
  • اندروید: Settings ← Network ← Private DNS را Off کنید، سپس در Wi-Fi گزینه IP Settings روی Static و DNS 1 را IP سرور بگذارید.
  • آیفون: Wi-Fi ← ⓘ ← Configure DNS روی Manual و IP سرور را اضافه کنید.
  • ویندوز: Network Adapter ← IPv4 Properties ← Use the following DNS و IP سرور.
  • پلی‌استیشن / ایکس‌باکس: Network Settings ← DNS Manual و IP سرور را وارد کنید.
۳. تست اتصال در سیستم کاربر: nslookup google.com

➕ کاربر جدید

اگر IP را نداری خالی بگذار؛ لینک اختصاصی برایش می‌سازی و با اولین باز شدن لینک، IP خودش ثبت می‌شود.
